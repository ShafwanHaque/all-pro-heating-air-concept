# All Pro Heating, Air & Electrical Website Concept

Standalone outreach preview shaped around the company’s published services and identity.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect site: https://www.allproheatingair.com/
- The supplied All Pro logo and service-van image are stored locally at `public/brand/all-pro-supplied-logo.png` and `public/hero/all-pro-service-van.png`. The hero places the van image over a navy background; the header frames the supplied logo on the same navy so its blue, green, and white lettering stays legible. The favicon uses the company’s blue, green, and navy colors.
- Company details, theme, contact information, and service areas are in `src/config/site.config.ts`; confirm them with the business before launch.
- The contact form is a preview and does not transmit submissions. Map tiles need an internet connection and show representative locations.
